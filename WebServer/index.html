Next steps

The Node.js server is running. To get the game in the browser:


1. Install AssetRipper and extract the Unity project from the client:

AssetRipper "Cliente 3.6.10.11"


2. Open the extracted project in Unity 6 Editor


3. Switch build target to WebGL and build


4. Copy the build output into PlayBrowser/WebClient/unity-build/


The game will then load at http://localhost:3000
